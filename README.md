# ModdingTools — сборки для тестеров

Закрытая бета инструментов для моддинга GTA V. Здесь только готовые сборки. Программа работает по ключу, который
выдаёт владелец.

## Установка

1. Откройте [последний релиз](https://github.com/TheBrainOne/moddingtools-releases/releases/latest) и скачайте
   `ModdingTools.exe`.
2. Положите файл в любую папку и запустите. Устанавливать ничего не нужно.
3. Windows может показать «Windows защитил ваш компьютер»: сборка пока не подписана. Нажмите «Подробнее» →
   «Выполнить в любом случае».
4. Введите ключ. Один ключ работает на одном компьютере. Программа проверяет его при каждом запуске, поэтому при
   запуске нужен интернет.

## Требования

- Windows 10 или 11, 64 бита.
- Microsoft Edge WebView2 Runtime. В Windows 11 он уже есть. Если программа сообщит, что его нет, установите его
  с сайта Microsoft.

## Обновления

Новые версии появляются здесь же. Если ваша версия устарела, программа скажет об этом и откроет страницу загрузки.

## Если что-то не так

Логи программы лежат в `%LOCALAPPDATA%\ModdingTools\logs`. Пришлите их тому, кто выдал вам ключ, вместе
с описанием: что делали, что ожидали и что получилось.

Контрольная сумма SHA-256 каждого `ModdingTools.exe` указана в описании его релиза.
